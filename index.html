SKIN BENCH

Drop a photo. Everything runs in this browser — nothing is uploaded, nothing is generated, nothing costs anything.
Every look is a pure pixel transform running on this device. The cutout looks (marked ·) run a 4.6 MB segmentation model locally — still no upload and no per-use cost, but it needs one pass per photo, so it is opt-in and the result is cached. Looks that invent content — paint by number, cross stitch, low poly, toon — cannot be done this way and would each cost a generation.
